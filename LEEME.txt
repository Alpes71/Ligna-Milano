PASOS
-----
1. git pull
2. Descomprime este ZIP sobre la carpeta del repositorio, respetando rutas
3. git add -A
4. git commit -m "Galeria de piezas y alineacion de marca"
5. git push
6. Sube a IONOS, EN ESTE ORDEN:
     a) la carpeta assets/img/productos/  (primero, siempre)
     b) index.html, aviso-legal.html, privacidad.html, cookies.html,
        condiciones.html
     c) assets/css/galeria.css, assets/css/cookie-banner.css,
        assets/js/galeria.js

Si subes index.html antes que las imagenes, la galeria mostrara huecos
rotos hasta que terminen de subir las fotos.
