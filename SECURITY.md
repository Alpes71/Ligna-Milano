# Política de seguridad

## Versiones soportadas

Este proyecto se mantiene en la rama `main`. Las correcciones de seguridad se aplican únicamente sobre la última versión publicada.

## Cómo reportar una vulnerabilidad

Por favor, **no abras un issue público** para reportar un problema de seguridad.

Usa el formulario privado de GitHub: https://github.com/Alpes71/Ligna-Milano/security/advisories/new

En el reporte, incluye si es posible una descripción del problema y su impacto, los pasos para reproducirlo, y la versión o el commit afectado.

## Qué puedes esperar

Confirmación de recepción en unos días, una valoración inicial con los siguientes pasos una vez revisado el reporte, e información sobre el avance hasta que el problema quede resuelto.

Si el reporte es válido, se dará crédito al autor en el aviso de seguridad publicado, salvo que prefiera permanecer anónimo.
